¿Cuál es la diferencia entre WHERE y HAVING?

Respuesta Profesional Esperada:

📄 Hoja de Trucos Rápidos de SQL para SSMS

Ten estas instrucciones a la mano mientras trabajas en SQL Server Management Studio:

1. Seleccionar la base de datos: 
USE DataCareer;
2. Traer columnas específicas: 
SELECT cliente_id, nombre, ciudad FROM analytics.dim_cliente;
3. Filtrar datos con comillas simples en texto: 
SELECT * FROM analytics.dim_cliente WHERE ciudad = 'Bogotá' AND edad >= 30;
4. Agrupar y contar registros: 
SELECT canal, COUNT(*) AS total FROM analytics.fact_llamadas GROUP BY canal;
5. Cruzar dos tablas con INNER JOIN: 
SELECT ll.llamada_id, c.nombre FROM analytics.fact_llamadas ll INNER JOIN analytics.dim_cliente c ON ll.cliente_id = c.cliente_id;
